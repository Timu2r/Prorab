# Отвес — ремонт и строительные работы

Платформа заявок и мастеров: ремонт под ключ, отделка, полы, фасады, электрика, сантехника, кондиционеры, вентиляция. ТЗ: [docs/TZ.md](docs/TZ.md).
Договоры: [dogovory/](dogovory/).

## Состав

| Папка | Что это | Порт |
|---|---|---|
| `apps/server` | API: Node + TypeScript + Fastify, PostgreSQL | 4100 |
| `apps/web` | Сайт для клиентов: Vite + React | 5190 |
| `apps/mobile` | Приложение для всех ролей: Expo — Android и браузер | 8082 (браузер) |
| `packages/core` | Общие правила: роли, статусы заявки, деньги, прайс по умолчанию | — |

## Запуск для разработки

1. Один раз: `pnpm install`, затем скопировать `apps/server/.env.example` в `apps/server/.env` и вписать свой номер
   в `OWNER_PHONES` — при входе с него выдаётся роль «Владелец».
2. Сервер: `pnpm dev:server`. База встроенная (PGlite, папка `apps/server/data/pg`), Docker не нужен.
3. Сайт: `pnpm dev:web`, открыть http://localhost:5190.
4. Приложение на телефоне: `pnpm dev:mobile`, открыть в Expo Go (телефон и компьютер в одной сети Wi-Fi).
5. Приложение в браузере: `pnpm --filter @ks/mobile web`, открыть http://localhost:8082.

Пока нет провайдера звонков, код входа пишется в консоль сервера и показывается на экране входа
(`DEV_CODES=1`). На боевом сервере это запрещено: сервер не запустится с `DEV_CODES=1` и `NODE_ENV=production`.

## Проверки

- `pnpm test` — тесты правил и API (права ролей, вход, статусы).
- `pnpm typecheck` — проверка типов во всех частях.
