# Платформа заявок и мастеров (ТЗ, к согласованию)

Рабочее название проекта: `klimat-servis` (переименуем, когда будет бренд).
Владелец: ИП Хамидов Т. Ш., Москва и Московская область, УСН 6%.
Допущения помечены **[К ПОДТВЕРЖДЕНИЮ]**. Эмодзи нигде не используются, только SVG-иконки (Tabler/Lucide).

## 1. Суть

Клиент заказывает работу на сайте или в приложении. Владелец согласует цену и назначает мастера. Мастер получает
задание в приложении, выполняет, отправляет фото и акт. Клиент платит на счёт ИП, мастер получает выплату по своей
ставке, владелец видит свой заработок по каждой заявке.

Услуги (расширено 2026-09-26 по решению владельца): **все ремонтные и строительные работы** — ремонт под ключ, отделка
стен и потолков, полы и плитка, фасады, электрика, сантехника и отопление, кондиционеры, вентиляция. Продажа
кондиционеров клиентам (закупка дешевле рынка, перепродажа с наценкой). Рабочее название бренда — «Прораб»
(`packages/core/src/brand.ts`), окончательное выбирает владелец.

## 2. Роли и каналы

| Роль | Чем пользуется | Главное |
|---|---|---|
| **Клиент** | **Сайт** и **приложение** (iOS, Android), один аккаунт по номеру телефона | Заказать работу, видеть статус, счёт, акт, гарантию, историю, записаться на ТО |
| **Мастер** | Приложение, режим «Мастер» | Принять задание, отметить статусы, фото, израсходованные материалы, свой заработок |
| **Владелец** | Приложение и веб-кабинет (с ПК удобнее) | Заявки, мастера, прайс, склад материалов, деньги, выплаты, отчёты |

Одно приложение на всех: роль определяется аккаунтом. Одна публикация в магазинах, одна сборка.

Вход по номеру телефона и **коду звонком** (flash call: код — последние цифры входящего номера; ≈0,5-1 ₽ за вход,
решение 2026-09-26). Провайдер звонков выбирается на этапе 5; в разработке код пишется в лог сервера.

## 3. Жизненный цикл заявки

```
Новая -> Согласована -> Счёт выставлен -> Предоплата получена -> Назначена -> Принята мастером -> Выехал -> На месте
      -> Выполнена -> Акт подписан клиентом -> Оплачена полностью -> Закрыта
Отмена возможна до статуса «Выехал», причина обязательна.
Отказ мастера -> заявка возвращается в «Предоплата получена» / «Согласована» для назначения другого.
```

| Статус | Кто ставит | Что происходит |
|---|---|---|
| Новая | Клиент (сайт/приложение) или владелец (звонок) | Push владельцу |
| Согласована | Владелец | Уточнены работы, дата, время, цена. Клиент видит итоговую смету |
| Счёт выставлен | Владелец | Счёт на оборудование и материалы (если нужны). Для работ без материалов шаг пропускается |
| Предоплата получена | Владелец / автоматически по оплате | Чек предоплаты клиенту |
| Назначена | Владелец | Push мастеру. Нет ответа 30 минут — push владельцу |
| Принята | Мастер | Мастеру открываются телефон и точный адрес клиента |
| Выехал / На месте | Мастер | Клиент видит статус и имя мастера |
| Выполнена | Мастер | Обязательно: фото «до» и «после», серийные номера, израсходованные материалы |
| Акт подписан | Клиент (кнопка в приложении/на сайте) или бумажный акт, фото которого загружает мастер | Запускается гарантия 12 месяцев |
| Оплачена полностью | Владелец / автоматически | Чек полного расчёта клиенту |
| Закрыта | Владелец | Начисляется выплата мастеру; клиенту гарантийный талон и просьба об отзыве |

Переходы проверяет сервер: мастер не может закрыть заявку, клиент не может отменить после выезда мастера.

## 4. Деньги

- Клиент платит **только на счёт ИП**. Мастер денег от клиента не принимает (п. 2.5 договора с мастером).
- Схема оплаты: **сначала счёт на оборудование и материалы**, после работ **оплата работ**.
- Оплата по ссылке или QR (СБП) через банк ИП; чек формирует **облачная касса** банка. На первом этапе владелец
  отмечает оплату вручную, интеграция с банком позже **[К ПОДТВЕРЖДЕНИЮ: банк ИП]**.
- В счёте и чеке раздельно: **товар** (кондиционер, материалы) и **услуга** (работы).
- **Ставка мастера** своя у каждого: процент от стоимости работ **или** фиксированный прайс по позициям (Приложение № 1
  договора). Ставка хранится с датой начала действия, старые заявки считаются по старой ставке.
- **Выплата мастеру** в течение 5 рабочих дней после подписанного акта. По самозанятым: перед выплатой проверка статуса
  через открытый сервис ФНС, после выплаты мастер загружает чек из «Моего налога»; без чека следующие выплаты
  приостанавливаются (п. 4.4 договора).
- **Удержания** из выплаты (переделка, ущерб) — только с указанием основания, попадают в акт-реестр.
- **По каждой заявке владелец видит:** выручку, себестоимость оборудования и материалов, выплату мастеру, налог 6%,
  свой остаток. Итог по месяцу и по каждому мастеру.

## 5. Материалы и оборудование

- Справочник: кондиционеры (модель, закупочная цена, цена продажи, серийный номер), расходники (медная труба за метр,
  кабель, дренаж, кронштейны, фреон и т. п.).
- Простой склад: приход (закупка), выдача мастеру, расход по заявке, возврат остатков.
- Мастер после работ указывает израсходованное; разница «выдано минус израсходовано» висит на мастере до возврата.
- Серийный номер кондиционера привязывается к заявке и клиенту: нужен для гарантии производителя.

## 6. Прайс для клиентов

Цены вписывает владелец, сайт и приложение показывают их сразу; позиция без цены показывается как «по смете».
Полный список (56 позиций, без цен) — `packages/core/src/services.ts`. Направления:

| Направление | Примеры позиций |
|---|---|
| Ремонт под ключ | Косметический / капитальный ремонт квартиры (м²), санузел под ключ, офис, демонтаж |
| Отделка стен и потолков | Штукатурка по маякам, шпаклёвка под покраску, покраска, обои, гипсокартон, потолок (м²) |
| Полы и плитка | Стяжка, ламинат и кварцвинил, плитка на пол и стены (м²), плинтус (м) |
| Фасады | Штукатурка, утепление, покраска фасада (м²), межпанельные швы, откосы и отливы (м), цоколь |
| Электрика | Замена проводки (м²), розетки (точка), автоматы, УЗО, свет, линия под кондиционер |
| Сантехника и отопление | Разводка труб (точка), радиаторы, смесители, унитазы, водонагреватели, течи, засоры |
| Кондиционеры | Монтаж 7-12 / 18-24 BTU, трасса (м), демонтаж, перенос, чистка и ТО, фреон, помпа |
| Вентиляция | Вытяжные вентиляторы, клапаны, воздуховоды (м), чистка |
| Другое | Выезд без работ, срочный выезд, работа на высоте |

**ОКВЭД:** для отделки (штукатурка, шпаклёвка, покраска, плитка) обычно нужны коды группы 43.3 (43.31, 43.33, 43.34,
43.39), для кровли — 43.91. В выписке ЕГРИП от 2026-09-26 их нет — добавить вместе с 47.54 **[К ПОДТВЕРЖДЕНИЮ у бухгалтера]**.

## 7. Экраны

### 7.1 Клиент (сайт и приложение, одинаковые возможности)
- Главная (сделано): направления, цены по вкладкам, как работаем, условия, вопросы, реквизиты ИП, политика обработки
  персональных данных (`/privacy`, черновик для юриста). Фото работ и отзывы — только настоящие, после первых объектов.
- **Быстрая заявка без входа (сделано):** имя, телефон, направление, коротко о задаче, согласие на обработку
  персональных данных -> заявка «Новая» у владельца. Защита: поле-ловушка, 5 заявок в час с адреса, 3 в сутки с номера.
  Клиент потом входит по коду на тот же номер и видит заявку в кабинете.
- Подробная заявка (в кабинете и приложении): направление -> работы -> фото -> адрес с картой -> дата и время.
- Мои заявки: статус по шагам, смета, счёт и кнопка оплаты, имя мастера, акт с кнопкой «Подписать», отмена до выезда.
- Мои кондиционеры: модель, дата установки, гарантия до такой-то даты, «Записаться на чистку».
- Напоминание о ТО через 6 и 12 месяцев после монтажа или чистки (push в приложении, на сайте — только при входе).
- Отзыв и оценка после закрытия.

### 7.2 Мастер
- Новые задания: работы, район, дата, время, сумма мастеру. «Принять» / «Отказаться».
- Сегодня и предстоящие: адрес, «Позвонить клиенту», «Маршрут» (Яндекс Карты), «Выехал», «На месте», «Готово».
- «Готово»: фото «до» и «после» (обязательно), серийные номера, израсходованные материалы, акт (подпись клиента на
  экране телефона или фото бумажного акта).
- Мой заработок: за месяц, выплачено, к выплате, удержания; загрузка чека самозанятого на каждую выплату.
- Мои материалы: что выдано и не возвращено.
- Мастер **не видит цену для клиента** (решение 2026-09-26), только свою выплату; другие мастера, чужие заявки и финансы
  владельца ему тоже недоступны.

### 7.3 Владелец
- Заявки: список с фильтрами, карточка, ручная заявка (звонок), согласование, счёт, назначение мастера (список
  подходящих по навыку, с загрузкой на день), подтверждение оплаты, закрытие.
- Мастера: карточка (навыки, статус самозанятого/ИП, ИНН, ставка, договор с датой), заработок, выплаты, акт-реестр за
  месяц в PDF (Приложение № 2 договора).
- Прайс, склад материалов и оборудования.
- Деньги: выручка, себестоимость, выплаты мастерам, налог, остаток; по месяцам и по мастерам. Выгрузка в Excel.
- Документы из заявки: смета/КП, счёт, акт, гарантийный талон (PDF, строгий чёрно-серый стиль).

## 8. Юридические требования (Россия)

- **Персональные данные (152-ФЗ):**
  - уведомление в Роскомнадзор до начала работы (pd.rkn.gov.ru);
  - политика обработки персональных данных на сайте и в приложении;
  - отдельное согласие клиента в форме заявки;
  - **сервер и база данных в России** (требование локализации) — хостинг только российский: Timeweb Cloud, Selectel,
    Yandex Cloud, VK Cloud;
  - мастер получает телефон и адрес клиента только после принятия задания и теряет доступ через [30] дней после закрытия.
- **Онлайн-касса (54-ФЗ):** чек на каждую оплату от физлица, включая переводы и СБП. Подключается перед первым заказом.
- **Защита прав потребителей:** срок работ в заявке фиксируется; клиент видит смету до оплаты; гарантийный талон с
  датой и сроком; претензии клиента логируются в истории заявки.
- **Самозанятые:** проверка статуса, хранение чеков, оплата за конкретную работу, а не за смену.
- **Магазины приложений:** Google Play ($25 разово), App Store ($99 в год, аккаунт на ИП). Обязательны политика
  конфиденциальности и удаление аккаунта из приложения.

## 9. Безопасность

- Каждый запрос проверяет роль и принадлежность данных: клиент видит только свои заявки, мастер только назначенные ему.
- Фото хранятся приватно, отдаются по временным ссылкам; геометки из фото удаляются при загрузке.
- Лимиты на создание заявок (против спама), на вход по коду, на загрузку файлов.
- Полная история изменений по заявке и по деньгам: ничего не стирается, только отмечается удалённым.
- Резервная копия базы и файлов ежедневно, хранение 30 дней.

## 10. Этапы разработки

Порядок выбран так, чтобы платформой можно было пользоваться **после каждого этапа**, а не только в конце.

| Этап | Содержимое | Чем можно пользоваться после |
|---|---|---|
| 0. Каркас | Репозиторий, сервер, база, вход, роли, выкладка на тестовый сервер | — |
| 1. Владелец | Прайс, мастера со ставками, ручные заявки, статусы, назначение | Принимать заказы по телефону и вести их в системе |
| 2. Мастер | Задания, статусы, фото, материалы, акт, push | Мастера работают через приложение |
| 3. Деньги | Счёт, отметка оплаты, выплаты мастерам, заработок по заявке, акт-реестр, PDF-документы | Полный учёт по заказу |
| 4. Клиент | Сайт и приложение клиента: заявка, статус, счёт, акт, гарантия | Заказы приходят сами |
| 5. Запуск | Российский хостинг, домен, публикация в Google Play и App Store, касса, политика ПДн | Работа с реальными клиентами |
| 6. Рост | Оплата по ссылке с автоматическим чеком, напоминания о ТО, отзывы, склад, отчёты | Повторные продажи |

Оценка: этапы 0-4 — **3-4 недели** работы; этап 5 зависит от проверки магазинами (1-7 дней) и регистрации
аккаунтов разработчика.

## 12. Стек (решение 2026-09-26)

| Часть | Решение |
|---|---|
| Приложение (клиент, мастер, владелец) | **Expo** (React Native), iOS и Android |
| Сайт (клиент) и веб-кабинет владельца | **Vite + React**, отдельное приложение |
| Сервер | Node.js + TypeScript, общий для сайта и приложения |
| База | PostgreSQL |
| Общий код | Пакет `core`: типы, статусы заявки и правила переходов, расчёт денег по заявке — одинаковые для сервера, сайта и приложения |
| Файлы | S3-совместимое хранилище российского облака (в разработке — локальная папка) |
| Push | Expo Push |

Структура:
```
klimat-servis/
  apps/server   # API
  apps/mobile   # Expo
  apps/web      # Vite + React: сайт клиента и кабинет владельца
  packages/core # общие типы и правила
  docs/         # ТЗ
  dogovory/     # договоры
```
