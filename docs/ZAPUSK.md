# Запуск «Отвеса» за 7 дней

Цель к концу недели: сайт открыт в интернете, заявка приходит владельцу SMS-сообщением, владелец назначает мастера,
мастер видит задание в телефоне и отмечает работу с фото, клиент платит по ссылке из банка с чеком.

Решения владельца (2026-09-26): ОКВЭД не добавляем; договор с отцом не нужен; оплата — счетами и ссылками из банка
(Т-Бизнес или Альфа) с автоматическим чеком; цены — рынок + 10%.

## Что будет готово к дню 7

| Кто | Чем пользуется | Что может |
|---|---|---|
| Клиент | Сайт | Оставить заявку, позвонить, посмотреть цены |
| Владелец | Веб-приложение «Отвес» (телефон и ПК, иконка на экране телефона) | Заявки, вопросы для звонка по направлению, статусы, назначение мастера, мастера, прайс. SMS о новой заявке |
| Мастер | То же веб-приложение, режим мастера | Задания, «Принять / Отказаться», «Выехал / На месте / Готово», фото до и после. SMS о новом задании |

Неделя 2: приложение для Android (RuStore и файл установки) с push-уведомлениями, деньги в системе (счета, выплаты
мастерам, заработок по заявке), приложение для клиентов.
